# 🌸 Mom's Birthday Website

A beautiful, warm, and emotionally meaningful birthday website crafted with pure **HTML, CSS, and Vanilla JavaScript**.

No frameworks, no npm, no backend required — **just double-click `index.html` to open it in any web browser!**

---

## 🚀 How to View the Website
Simply double-click **`index.html`** in this folder to open it in Chrome, Edge, Safari, or any browser.

---

## 📸 How to Add Your Mom's Photos

Inside the `images/` folder (or right alongside `index.html`), place your images named as follows:
- **`hero.jpg`** — Main portrait of your mom on the celebration hero banner.
- **`photo-1.jpg`** to **`photo-6.jpg`** — Memories for the Polaroid photo gallery.
- **`final.jpg`** — Closing photo at the bottom of the page.

> **Note:** If you haven't added photos yet, don't worry! The website automatically displays beautiful floral illustrations instead of broken image icons, so it always looks gorgeous.

---

## 🎵 How to Add Background Music (Optional)

1. Put your favorite song (instrumental piano or acoustic guitar works best!) in the folder:
   `audio/music.mp3`
2. The website includes a floating **"Play Music"** button at the top right.
3. *Bonus:* If no audio file is provided, clicking the music button will automatically generate a gentle, soothing chime melody using Web Audio!

---

## ✍️ How to Personalize the Messages

Open `index.html` with any text editor (Notepad, VS Code, etc.):
- Search for `Dearest Mom` to customize the personal letter.
- Edit the captions under the Polaroid gallery (look for `data-caption="..."`).
- Search for `Things I Love About You` to change the 6 special cards.
